🏷️ Step 2: Key Normalization

rename-json-keys

Recursively rename keys in any JSON structure using a simple dictionary map. Zero dependencies, 100% data preservation.

🎮 Open Interactive Playground 🐙 GitHub Repository 📦 npm Package

💡 Why use rename-json-keys?

JavaScript has no native way to recursively rename keys in deeply nested objects and arrays without writing manual traversal code or mutating your original data.

🔁 Truly Recursive

Renames keys everywhere across nested objects, arrays, and sub-collections in a single pass.

🔒 Non-Destructive

Never mutates your input data. Values, array order, and data structures remain 100% intact.

⚡ Zero Dependencies

Lightweight and lightning fast with zero third-party packages or bundle bloat.

📐 Simple Dictionary Map

Just specify { "oldKey": "newKey" }. No complex regex or heavy configurations needed.

🚀 Quick Start (5 Seconds)

Install via npm:

npm install rename-json-keys

Pass your data and a key map:

import { renameJsonKeys } from "rename-json-keys";

const user = {
  user_id: 101,
  contact_info: {
    first_name: "John",
    last_name: "Doe",
    email_addr: "john@example.com"
  }
};

const keyMap = {
  user_id: "id",
  first_name: "firstName",
  last_name: "lastName",
  email_addr: "email"
};

const result = renameJsonKeys(user, keyMap);
console.log(result);

Clean renamed output:

{
  "id": 101,
  "contact_info": {
    "firstName": "John",
    "lastName": "Doe",
    "email": "john@example.com"
  }
}
