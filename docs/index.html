01 · Problem

The data is useful. The keys are not always useful.

External systems often return field names that do not match the naming convention used by an application.

Changing the values or rebuilding the whole JSON structure just to rename fields adds unnecessary work.

Goal: keep the JSON data exactly where it is and change only the key names.
