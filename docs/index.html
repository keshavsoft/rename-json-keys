rename-json-keys

Recursively rename keys in any JSON structure using a simple dictionary map. Zero dependencies, 100% data preservation.

1. Source JSON
2. Rename Dictionary
3. Live Output 

      

    


    
    

      
      

        
Installation & Usage

        
Install via npm:

        
npm install rename-json-keys

        
Pass your data and mapping dictionary:

        
import { renameJsonKeys } from "rename-json-keys";

const clean = renameJsonKeys(data, keyMap);

      


      
      

        
Core Guarantees

        
    
          
  • 🔁 Truly Recursive: Renames keys across all nested objects and arrays.
    • 
          
  • 🔒 Non-Destructive: Input data, values, and array order are 100% preserved.
    • 
          
  • ⚡ Zero Dependencies: Lightweight pure JavaScript with no bundle bloat.
    • 
          
  • 📐 Simple Mapping: Just pass a clean { "oldKey": "newKey" } dictionary.
