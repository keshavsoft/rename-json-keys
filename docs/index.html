Quick API Guide

      
Install via npm:

      
npm install rename-json-keys

      
      
Import and execute with zero dependencies in Node.js, modern bundlers, or browsers:

      
import { renameJsonKeys } from "rename-json-keys";

const clean = renameJsonKeys(vouchers, {
  "DATE": "date",
  "ALLINVENTORYENTRIES.LIST": "items",
  "STOCKITEMNAME": "itemName",
  "BATCHALLOCATIONS.LIST": "batches",
  "MFDON": "mfdOn",
  "GODOWNNAME": "godownName"
});


      
Load directly in browsers from jsDelivr CDN:

      
<script type="module">
  import { renameJsonKeys } from "https://cdn.jsdelivr.net/gh/keshavsoft/rename-json-keys@main/docs/dist/min.js";
  const result = renameJsonKeys(data, keyMap);
</script>
