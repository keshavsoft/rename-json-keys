Pure JSON Utility

rename-json-keys

Recursively rename ugly enterprise keys to clean, readable names across nested objects and arrays with zero data mutation.

1. Source JSON Data
2. Key Mapping Dictionary
3. Renamed Output JSON 

      

        Execution Time: 0 ms
        Original Keys Replaced: 0
      

    


    
    

      
Quick API Guide

      
Install via npm:

      
npm install rename-json-keys

      
      
Import and use anywhere in Node.js or modern frontend frameworks:

      
import { renameJsonKeys } from "rename-json-keys";

// Call with positional arguments or KeshavSoft { inData, inKeys } object
const clean = renameJsonKeys(sourceData, {
  "ITEM_IDENTIFIER": "id",
  "NESTED_INVENTORY_COLLECTION": "items"
});
