05 · Usage

Use it as a small transformation step.

Install

npm install rename-json-keys

Conceptual usage

import rename from "rename-json-keys";

const output = rename(sourceJson, renameMap);

Guarantees

  • Renames keys recursively.
  • Preserves values.
  • Preserves the JSON hierarchy.
  • Does not mix key renaming with unrelated data normalization.
