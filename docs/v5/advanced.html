Use explicit mapping rules when the transformation needs more control.

For nested structures, the mapping can describe the same hierarchy as the input. This keeps the transformation predictable and readable.

{
  "customer": {
    "first_name": "name",
    "address": {
      "zip_code": "postal_code"
    }
  }
}

Keep the mapping focused on naming. Shape normalization and value conversion are separate concerns.
