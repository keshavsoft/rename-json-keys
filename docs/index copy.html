JSON transformation

Rename JSON keys without changing the data.

Give it JSON and a rename map. The values and structure stay intact; only the keys change.

The idea

{
  "first_name": "John",
  "age": 30,
  "city": "Kakinada"
}
{
  "first_name": "name",
  "age": "years",
  "city": "location"
}
{
  "name": "John",
  "years": 30,
  "location": "Kakinada"
}
